# PoketDieCast
## A personal project and portfolio

-------------------------------

# Why this project

I have small diecast collection of cars and I wanted to always be able to see what's in my collection, but I don't want to just have a written list on my phone or a folder of pictures. 
I want something more structured and pleasing to use. Here comes PoketDieCast, where Poket is a mix of "Pocket" for its portability and "Poke" as in Pokemon, as this helps you "collect them all".

-------------------------------

# What is this project

This project will offer two access points, an android app and a webpage, where someone can create their account and store their collection of diecasts.
This will be possible through a form with multiple types of data reguarding the cars. 
To have it sync between app and webpage it will be possible to use a manual export-import system or *hopefully* in the future there will be a self-hosted version of the server.
